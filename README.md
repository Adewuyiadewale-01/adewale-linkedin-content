# adewale-linkedin-content

Portable Agent Skill for planning, drafting, auditing, revising, and learning from Tony's Adewale LinkedIn content.

The skill uses the open `SKILL.md` + supporting resources pattern and keeps the strategy, voice guide, content system, and performance log in `references/` for progressive disclosure.

## Structure

```text
adewale-linkedin-content/
├── SKILL.md
├── README.md
└── references/
    ├── 00-README.md
    ├── 01-adewale-strategy.md
    ├── 02-adewale-voice-guide.md
    ├── 03-adewale-content-system.md
    └── 04-adewale-content-log.md
```

## Install

### Codex

Copy or symlink this repository into your Codex skills directory.

### Claude Code

Place the folder at `~/.claude/skills/adewale-linkedin-content/` for a personal skill, or `.claude/skills/adewale-linkedin-content/` inside a project.

### Claude.ai

Zip the repository folder and upload it as a custom Skill.

### Google Antigravity

Place it at `<workspace>/.agents/skills/adewale-linkedin-content/` for a workspace skill or `~/.gemini/config/skills/adewale-linkedin-content/` for a global skill.
